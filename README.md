# FlowCode — 可视化程序逻辑

FlowCode 是一个 VS Code 扩展：把 Python 函数或 Jupyter Notebook 变成一张由「方法模块 + 参数连线」组成的流程图，并且可以双向同步。

- **左侧方法栏**：内置运算符、数学、文本、列表、数据/AI 方法，以及当前文件里的函数；拖到画布即复制一个新的可编辑实例。
- **中间流程图**：方法模块的每个输入/输出参数都有端口和名称；输出端口连到下一个方法的输入端口，参数胶囊也可以直接拖到输入端口。
- **右侧参数面板**：可折叠。编辑方法效果、参数名、类型、默认值；默认参数直接显示在模块上。
- **参数行直接编辑**：点击模块左侧/右侧的参数行，弹出小编辑器改名称、类型、默认值；不用先打开右侧面板。
- **非继承参数进接口**：没有上游连线的输入不再单独生成输入胶囊，而是直接写成参数行的默认值；字面量也折叠进接口。
- **继承层级布局**：横向按变量/参数依赖分层。互不依赖的 add、menos 在同一列，消费它们结果的 xiangjia 进入下一列。
- **平行关系对齐**：两个方法汇入同一个下级时（末端平行），右侧对齐；一个方法分叉给两个下级时（前端平行），左侧对齐。
- **方法工作室**：方法列表上方的入口，用 API + 需求生成方法；代码、输入/输出参数、方法块预览四栏联动，完成后直接建立可编辑方法块。
- **自适应布局**：横窗口横向排列，竖窗口纵向排列，并根据窗口尺寸拉开间距、尽量填满画布；手动缩放窗口会重新排版。
- **端口聚焦**：点击任意端口圆点，淡化与它无关的连线，同时保留并标出这条数据继续往下游的整条链路与用途清单。
- **Jupyter**：`.ipynb` 支持“全部 Cell”汇总视图和按 Cell 查看；单 Cell 模式可写回。
- **文件关系**：顶部“文件关系”把工作区 `.py` 文件按 import 关系画成图，查看 util / pkg 的导入与被导入。
- **双向转换**：从当前 Python 文件解析出流程图；改完图后一键生成代码并替换入口函数。
- **复制与修改**：`Alt / Option + 拖动` 模块可复制实例；复制后每个参数、效果都能独立改。

## 安装

### 从 VSIX 安装

1. 下载 `flowcode-vscode-0.1.0.vsix`。
2. VS Code → 扩展视图 → 右上角 `…` → **从 VSIX 安装…**。
3. 打开一个 `.py` 文件，点击编辑器右上角的流程图图标，或执行命令 **FlowCode: 打开流程图**。

也可以在命令行安装：

```bash
code --install-extension flowcode-vscode-0.1.0.vsix
```

### 环境要求

- VS Code 1.90+
- Python 3.9+（用于解析 AST；不需要安装任何第三方库）

如果自动检测不到 Python，在设置中配置：

```json
"flowcode.pythonPath": "C:/path/to/python.exe"
```

## 使用

1. 打开一个 Python 文件，把光标放在想查看的函数里（或直接打开 `main`）。
2. 点击编辑器标题栏的流程图按钮。FlowCode 会解析当前函数，绘制数据流。
3. 从左侧拖入方法，或点方法卡片上的 `+`。拖入是复制实例；新方法会按参数名自动接线，有默认值的参数保持默认。
4. 从输出端口拖到下一个方法：**落在卡片任意位置即可**，系统按落点最近的参数行决定连到哪个输入口；拖到空白处会创建流程输出。
5. 直接点击模块上的参数行，或使用右侧面板，修改参数名、类型、默认值；没有上游的参数会以默认值写在接口里，有连线的参数保持连线。
6. 需要方法变体时，`Alt / Option + 拖动` 复制一个实例，再独立修改它的参数。
7. 点右上角 **应用到代码**，预览生成的 Python，确认后写回编辑器。
8. `Ctrl+S` 保存。没有未应用修改时，保存后会自动刷新流程图。

### 接线：整卡可落，按行吸附

- 拖线或拖参数胶囊时，只要落点能确定是哪个模块、哪一行，就能连上：**落在卡片内任意位置** → 连到该卡片在这一侧最近的那个端口（不会连到别的模块）。
- 落点在卡片外时，端口周围约有 84px（屏幕像素）的吸附范围；再远才算空白，从方法输出端口拖到空白才会生成流程输出。
- 拖动过程中会**预览落点**：目标卡片描边、命中的那一行高亮、对应端口放大发光，预览连线直接吸到端口上，松手前就能确认。
- 参数胶囊落到卡片上后会自动归位到该行的左侧标准位置；落在没有可接端口的卡片上会提示，不会乱丢节点。

### 聚焦：参数与端口

- 点击**端口圆点**（输入或输出）：只保留这个端口直接相关的连线，并把它的**后续用途**一并点亮——下游每一段连线用虚线显示，不会因为“与端口无关”被淡化掉。顶部聚焦条显示“后续 N 处”的用途概要，右侧面板列出完整链路，点列表项可直接跳到对应模块。
- 点击一条连线，或点击一个参数胶囊：画布只强调这条参数传递（参数胶囊会强调它的所有连线），其他连线和无关节点会淡化。
- 再点一次同一个端口、按 `Esc`、点右侧的 ×，或点击空白处都可恢复。
- 端口点击区为 26×26，排列仍按参数行紧密排布，相邻端口互不重叠；按下后拖动就是接线，只有“按下即松开”才是聚焦。

### 方法工作室

方法库上方的 **方法工作室** 用来从需求生成一个新方法块：

1. **API Key**：可选，输入后保存在 VS Code SecretStorage，不出现在流程图、导出 JSON 或设置里。未配置时使用本地模板生成。
2. **方法要求**：写清楚输入、输出、业务规则；点 **AI 生成**。
3. **四栏联动**：
   - 左：输入参数（名称、类型、默认值）
   - 中：完整 Python 代码，可直接编辑
   - 右：输出参数
   - 最右：方法块预览、AI 生成的方法介绍与详细说明
4. 改参数会同步改代码签名；改代码签名会反向同步参数。
5. 右下角 **完成并建立方法块**：加入方法库，并自动放到当前画布。

AI 使用 OpenAI 兼容接口，可在设置中改地址和模型：

```json
"flowcode.aiBaseUrl": "https://api.openai.com/v1",
"flowcode.aiModel": "gpt-4o-mini"
```

请求只包含方法要求和你填写的代码；API Key 通过 `Authorization: Bearer` 发送到你配置的地址。

### Jupyter Notebook

打开 `.ipynb` 后点击 Notebook 工具栏的流程图按钮，或执行 **FlowCode: 打开流程图**。

- 顶部 Cell 下拉框：**全部 Cell** 把所有代码单元拼成一个总流程图；选择 **Cell N** 只显示该单元。
- “全部 Cell”里每个方法带 `C1`/`C2` 小标签，表示来自哪个代码单元。
- 只有在单 Cell 模式下才能“应用到代码”；写回会整体替换该 Cell，但会保留顶部 import / 魔法命令和顶层 def/class。
- 魔法命令（`%matplotlib`、`!pip`）会被忽略并保留在写回内容中。

### 文件关系

点顶部 **文件关系**：

- 每个 `.py` 文件是一张卡片，显示目录、函数/类、导入数、被导入数。
- 箭头从“导入方”指向“被导入文件”；点击连线会淡化其他关系，点击文件在右侧查看 import 列表、被导入列表和外部依赖。
- 目前扫描工作区（最多 300 个文件），跳过 `node_modules / .venv / __pycache__ / dist` 等目录。
- 只展示项目内可解析的相对/绝对模块；`math`、`numpy` 等外部依赖列在右侧“外部依赖”。

### 入口函数

顶部 `demo.py / main()` 下拉框可以切换入口函数。选一个函数，FlowCode 会展示这个函数内部的数据流；其他函数会出现在左侧「当前文件」里，可以拖入当前流程。

### 生成的代码

FlowCode 只替换入口函数，文件里的其他函数、导入、注释会保留。生成规则：

- 方法模块 → 函数/运算符调用
- 参数胶囊 → 变量或字面量
- 流程输入 → 函数参数
- 流程输出 → `return`
- 有默认值且未连接的参数 → 默认值表达式
- 未连接的必填输入 → `None`，并在右侧给出提示

## 支持的 Python 范围

- 函数定义、参数注解、默认值、docstring
- 赋值、增强赋值、返回
- 函数/方法调用、属性方法、二元/一元/比较/布尔运算
- 字面量、列表/元组常量、切片（`[]`）
- `if / for / while / try / with` 会按顺序展开并给出「控制流」提示；**直接写回会丢失分支结构**，应用前会二次确认。
- 类的方法会作为方法库条目出现，但入口函数目前取顶层函数。
- Notebook 的“全部 Cell”是拼接后的汇总视图，不能直接写回；单 Cell 写回会保留顶部 import/魔法和顶层 def/class，但控制流仍会被展开。
- 文件关系只做静态 import 扫描，不执行代码；动态 import、`sys.path` 操作和外部包内部关系不在图里。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做画布操作 |
| `Alt / Option + 拖动模块` | 复制一个方法实例 |
| `Delete` / `Backspace` | 删除选中的模块、参数或连线 |
| `Ctrl+Enter` | 打开「应用到代码」预览 |
| `F` | 适应窗口 |
| 点击连线 / 参数胶囊 | 聚焦该参数传递，淡化其他线 |
| 点击端口圆点 | 聚焦该端口的后续链路，淡化无关连线 |
| 滚轮 | 缩放画布（以鼠标位置为中心） |
| 拖空白处 | 平移画布 |
| 拖动参数胶囊或端口到输入端口 | 建立连线 |
| `Esc` | 关闭预览 / 取消选择 / 取消聚焦 |

## 开发

```bash
pnpm install
pnpm build        # 构建 dist/extension.js 与 dist/webview.js
pnpm test         # 核心解析/生成测试
pnpm typecheck
pnpm package      # 生成 VSIX
```

调试：用 VS Code 打开本目录，按 `F5`（已提供 `.vscode/launch.json`）启动 Extension Development Host，然后打开 `test/fixtures/sample.py`。

### 目录结构

```
src/
  extension.ts          VS Code 扩展宿主、Webview 生命周期、写回代码
  pythonBridge.ts       启动 Python、通过 stdin/stdout 传递 AST 结果
  core/
    types.ts            FlowGraph / MethodSpec / Port 等类型
    registry.ts         内置方法库
    graph.ts            图操作、连线、环检测、自动补参数、自由位置
    layout.ts           分层数据流布局
    enrich.ts           把解析结果补全为可渲染的图
    generate.ts         流程图 → Python
    sample.ts           内置演示图
python/parse_flow.py    Python AST → FlowGraph JSON
webview/src/            React 三栏界面（方法库 / 画布 / 参数面板）
```

### 数据流

```
Python 源码
  └─ python/parse_flow.py (ast)
       └─ FlowGraph JSON
            ├─ 布局 + 内置方法补全
            └─ webview 渲染
                 └─ 用户编辑
                      └─ generate.ts → Python
                           └─ WorkspaceEdit 替换入口函数
```

## 已知边界

- 流程图是**数据流**视图，不表达控制流。分支/循环会线性展开并标注，应用前请预览。
- 只替换入口函数；跨函数的内联/重构不在当前范围。
- 应用代码前会重新解析以定位入口函数；如果函数被重命名或删除，会提示先刷新。
- 生成的代码不会自动补 `import`；右侧代码页会列出需要的模块。
